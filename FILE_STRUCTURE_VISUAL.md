## 📋 API Routes (Defined in main.go)

```
Health Check:
  GET /ping
       ↓ handlers (implicit)

Digital Twin (Core):
  GET /houses
       ↓ houseHandler.GetHouses
       ↓ db/db.go connection
       ↓ MySQL query
  
  GET /house/:id
       ↓ houseHandler.GetHouseByID
  
  GET /location-options
       ↓ locationHandler.GetLocationOptions

Dashboard Insights:
  GET /insights/governance
  GET /insights/agriculture
  GET /insights/welfare
       ↓ insightHandler.Get*Insights
       ↓ db/db.go connection

Farmer Registry:
  GET /farmers
       ↓ farmerHandler.GetFarmers
       ↓ FAMILY + FAMILY_MEMBER join

PDF Reports:
  POST /pdf/report
       ↓ pdfHandler.GeneratePDF
       ↓ Parse JSON request
       ↓ Query database
       ↓ Generate PDF
       ↓ Stream to browser

Agricultural Data (Legacy):
  GET /crops       → cropHandler.GetCrops
  GET /land        → landHandler.GetLand
  GET /irrigation  → irrigationHandler.GetIrrigation

Static Data (In-Memory):
  GET /soil        → handlers.GetSoil
  GET /schemes     → handlers.GetSchemes
  GET /market      → handlers.GetMarket
```

## 🎯 Request Flow Example

### User navigates to /map (MapView.vue)

```
Step 1: User clicks "2D Map" in App.vue sidebar
        ↓
Step 2: Vue Router routes to /map
        ↓ src/router/index.js detects /map
        ↓ Loads views/MapView.vue
        ↓
Step 3: MapView.vue onMounted():
        ├─ Call: getLocationOptions() [api/index.js]
        │  └─ Fetch: GET /api/location-options
        │     └─ Backend: locationHandler.GetLocationOptions()
        │        └─ Query: district_master, taluka_master, village_master
        │        └─ Return: JSON {districts, talukas, villages}
        │
        ├─ Render: <select> dropdowns with options
        │
        └─ Show: Leaflet map (no data yet)
        ↓
Step 4: User selects: District="Satara", Taluka="Karad", clicks "Apply"
        ├─ Call: getHouses({district_id:1, taluka_id:2, page:1, limit:500})
        │  └─ Fetch: GET /api/houses?district_id=1&taluka_id=2&...
        │     └─ Backend: houseHandler.GetHouses()
        │        ├─ Parse params
        │        ├─ Build: WHERE district_id=1 AND taluka_id=2
        │        ├─ Query: SELECT ... FROM FAMILY LIMIT 500 OFFSET 0
        │        └─ Return: JSON {data: [...500 houses...], total: 3200, ...}
        │
        ├─ Frontend: houses.value = [...500 households...]
        │
        └─ Render: Leaflet markers for each household
        ↓
Step 5: User clicks household marker
        ├─ Show: Detail panel with full household info
        │        (All data already in browser, no API call)
        │
        └─ Can: Zoom to location, see crops, water source, etc.
        ↓
Step 6: User clicks "Heatmap" view mode
        ├─ Frontend: buildHeatmap()
        │  ├─ Create canvas 2x resolution
        │  ├─ Draw blur circles for each household
        │  ├─ Colorize by metric
        │  └─ Overlay on Leaflet
        │
        └─ Show: Smooth density heatmap (no API call needed!)
```

## 🔀 Data Flow Directions

```
PULL (Frontend requests from Backend):
  Browser ─(GET)─→ Go API ─(SELECT)─→ MySQL ─→ Go API ─(JSON)─→ Browser
  Example: /houses endpoint

PUSH (Browser sends data to Backend):
  Browser ─(POST + JSON)─→ Go API ─(SELECT+compute)─→ MySQL ─→ Generate PDF
  Example: /pdf/report endpoint (reads database, doesn't modify)

COMPUTE (Browser-only, no API):
  Browser ─→ Problem detection (all in Vue)
  Browser ─→ Heatmap rendering (all in canvas)
  Example: DigitalTwin.vue matchesProblemFilter()
```

## 🎨 Frontend Structure Pattern

All views follow same pattern:

```
<template>
  <!-- HTML structure for page -->
  <header>...</header>
  <sidebar>...</sidebar>
  <main>
    <!-- Renders dynamic data from JS -->
  </main>
</template>

<script setup>
import { ref, computed, onMounted } from 'vue'
import { getHouses } from '../api/index.js'

// State
const houses = ref([])
const search = ref('')

// Computed (reactive filtering)
const filtered = computed(() => 
  houses.value.filter(...)
)

// Methods
async function loadData() {
  houses.value = await getHouses()
}

// Lifecycle
onMounted(() => loadData())
</script>

<style scoped>
/* Component styles (scoped to this component) */
</style>
```

Every view:
1. Imports API functions
2. Manages local state with `ref()`
3. Computes filtered data with `computed()`
4. Calls API on `onMounted()`
5. Renders with template

## 🔐 Security Architecture

```
Untrusted Input (Browser)
         ↓
Vite Dev Server Proxy
  (localhost:5173 → :8081)
         ↓
Go Backend (main.go)
  ├─ Middleware: CORS check
  ├─ Middleware: Request logging
  ├─ Middleware: Read-only enforcement
  │  └─ BLOCK: DELETE, PUT, PATCH
  │  └─ ALLOW: GET, POST /pdf/*
  │  └─ RESULT: Data corruption impossible
  ├─ Handler: Parse + validate params
  ├─ Handler: Build parameterized queries
  │  └─ RESULT: SQL injection impossible
  └─ Handler: Return sanitized JSON
         ↓
MySQL Database (read-only user)
  └─ Further protection: DB user has SELECT only
         ↓
Browser receives JSON
```

**Result**: Multiple layers of defense
- Frontend can't send dangerous requests
- Backend blocks dangerous operations
- Database user is read-only
- No possibility of data corruption
